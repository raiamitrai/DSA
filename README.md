# Data Structures and Algorithms (DSA) in Java

Welcome to the **Data Structures and Algorithms** repository! This repository contains implementations, solutions, and practice problems written in Java.

---

## 📌 Repository Structure & Branching Workflow

This repository follows a feature/topic branch workflow:

```text
main (Base Branch)
 ├── linkedlist
 ├── stack
 ├── queue
 ├── trees
 └── graphs
```

- **`main`**: The core base branch containing documentation and repository setup.
- **Topic Branches**: All topic implementations (e.g. `linkedlist`, `stack`, etc.) are created from `main` and merged into `main` after completion.
